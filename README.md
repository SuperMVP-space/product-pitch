# Product Pitch

Самостоятельный инструмент для авторов продуктов и предпринимателей:
помогает понятно представить замысел или показать фактический результат.
Подходит для первого и следующих продуктов, включая личные и бесплатные.

Два режима:

- **Представить идею:** карточка, дизайн-док или описание → содержание пяти
  слайдов и черновик речи ориентировочно на 90 секунд.
- **Показать результат:** продукт, прежний дек и доступные отзывы → обновлённые
  пять слайдов, речь, сравнение замысла с фактом, демо-план, ответы на вопросы
  и только необходимые перед показом правки.

Неполные входы позволяют сделать честный черновик. Предположения и сообщения
автора отделяются от проверенных результатов. Оценка времени речи требует
проверки реальным прогоном; отсутствие доступа к продукту не заменяется
заявлением о готовности.

## Начать

Загрузите [SKILL.md](SKILL.md) и выбранную справку из `references/`
в среду, поддерживающую скиллы. Либо передайте эти тексты AI-чату.
Редактор презентаций для подготовки содержания не требуется.

Два примера запросов:

> Помоги представить идею. Вот описание моего продукта: …
> Подготовь пять слайдов и короткую речь для людей без контекста.

> Помоги показать результат. Вот продукт, старый дек и отзывы: …
> Обнови питч и подготовь воспроизводимый сценарий демонстрации.

Инструкция находится в корне репозитория; дополнительные процедуры —
[питч идеи](references/idea-pitch.md) и
[показ результата](references/product-pitch.md).
